# Mahosample Public User Guide

คู่มือนี้สำหรับลูกค้าทั่วไปที่ต้องการลงทะเบียนรับตัวอย่าง มะโฮ และตรวจสอบสถานะพัสดุหลังได้รับเลข tracking จากเจ้าหน้าที่

## 1. เข้าใช้งานหน้าแบบฟอร์ม

1. เปิดหน้า `http://maho.kitaith.com:18080/`
2. ตรวจสอบหัวข้อ `ลงทะเบียนรับตัวอย่าง มะโฮ`
3. อ่านข้อมูลกิจกรรมรับตัวอย่างมะโฮแบบเจล ฟรี 2 ซอง

## 2. กรอกข้อมูลผู้ลงทะเบียน

ข้อมูลที่ต้องกรอก:
- ชื่อ-นามสกุล
- เบอร์โทรศัพท์
- ช่องทางติดต่ออย่างน้อย 1 อย่าง: อีเมล, LINE ID หรือ Facebook Messenger
- ช่วงอายุ
- ความสนใจด้านสุขภาพ
- ประสบการณ์กับ มะโฮ

ระบบอนุญาตให้เลือกกรอก อีเมล, LINE ID หรือ Facebook Messenger อย่างใดอย่างหนึ่งได้ แต่ต้องมีอย่างน้อย 1 ช่องทาง เพื่อให้เจ้าหน้าที่แจ้งเลข tracking หลังจัดส่ง

## 3. กรอกข้อมูลจัดส่ง

ข้อมูลจัดส่งที่ต้องกรอก:
- ชื่อผู้รับ
- บ้านเลขที่/อาคาร/หมู่บ้าน
- ถนน/ซอย หรือรายละเอียดเพิ่มเติมถ้ามี
- ตำบล/แขวง
- อำเภอ/เขต
- จังหวัด
- รหัสไปรษณีย์

ควรตรวจสอบชื่อผู้รับและที่อยู่ให้ถูกต้องก่อนส่งแบบฟอร์ม เพราะระบบใช้ข้อมูลนี้ตรวจสิทธิ์และใช้จัดส่งตัวอย่าง

## 4. ยินยอมใช้ข้อมูลส่วนบุคคล

ก่อนส่งแบบฟอร์ม ต้องติ๊กยินยอมให้ใช้ข้อมูลเพื่อ:
- ตรวจสอบสิทธิ์
- ติดต่อกลับ
- จัดส่งตัวอย่าง มะโฮ

การยินยอมรับข่าวสารหรือโปรโมชั่นในอนาคตเป็นตัวเลือก ไม่บังคับ

## 5. ส่งแบบฟอร์มสำเร็จ

เมื่อส่งแบบฟอร์มสำเร็จ ระบบจะแสดง card:
- `ส่งแบบฟอร์มเรียบร้อย`
- `ลงทะเบียนสำเร็จ`
- เลขรายการภายใน เช่น `MS202609020025`
- ข้อความแจ้งว่าเจ้าหน้าที่จะส่งเลข tracking ให้ทาง LINE ID หรือ Facebook Messenger หลังจัดส่งแล้ว

ลูกค้าควรจดหรือบันทึกเลขรายการภายในไว้ เผื่อติดต่อเจ้าหน้าที่ภายหลัง

## 6. กรณีข้อมูลซ้ำ

ถ้าระบบพบว่าข้อมูลเคยลงทะเบียนแล้ว ระบบจะแจ้งสาเหตุ เช่น:
- เบอร์โทรศัพท์นี้เคยลงทะเบียนแล้ว
- ที่อยู่จัดส่งนี้เคยลงทะเบียนแล้ว
- เบอร์โทรศัพท์และที่อยู่จัดส่งนี้เคยลงทะเบียนแล้ว

หากพบข้อความซ้ำ ให้ติดต่อเจ้าหน้าที่แทนการกรอกซ้ำ

## 7. ตรวจสอบสถานะพัสดุ

หลังจากเจ้าหน้าที่จัดส่งแล้ว ลูกค้าจะได้รับเลข tracking ผ่านช่องทางที่ให้ไว้ เช่น LINE ID หรือ Facebook Messenger

วิธีตรวจสอบ:
1. เปิดหน้า `http://maho.kitaith.com:18080/tracking`
2. กรอกเลข tracking เช่น `JC012366691TH`
3. กด `เช็คสถานะ`
4. ตรวจสถานะคำขอและสถานะขนส่งในระบบ
5. กดลิงก์ `เปิดหน้า Thailand Post` หากต้องการดูข้อมูลจากไปรษณีย์ไทยโดยตรง

## 8. ไม่พบเลข tracking

หากระบบแจ้งว่าไม่พบเลข tracking:
- ตรวจว่ากรอกเลขถูกต้อง
- ตรวจตัวอักษรภาษาอังกฤษและตัวเลขอีกครั้ง
- หากยังไม่พบ ให้ติดต่อเจ้าหน้าที่เพื่อให้ตรวจสอบรายการจัดส่ง

## 9. แนวทางความปลอดภัยของข้อมูล

- ไม่ควรโพสต์เบอร์โทรศัพท์หรือที่อยู่ใต้โพสต์สาธารณะ
- ใช้แบบฟอร์มหรือ inbox ตามช่องทางที่บริษัทกำหนด
- ข้อมูลถูกใช้เพื่อการตรวจสอบสิทธิ์ ติดต่อกลับ และจัดส่งตัวอย่างตามวัตถุประสงค์ที่แจ้งไว้
