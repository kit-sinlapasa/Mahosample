# Mahosample Test Cases

เอกสารนี้รวม test case ตาม flow หลักของระบบ Mahosample สำหรับใช้ทดสอบก่อน demo, release หรือส่งงาน

## ขอบเขตการทดสอบ

- หน้าแบบฟอร์มลงทะเบียนรับตัวอย่าง มะโฮ สำหรับลูกค้าทั่วไป
- หน้าเช็คสถานะด้วยเลข tracking
- หน้า Dashboard พนักงาน
- หน้าตารางข้อมูลเต็มของพนักงาน
- การบันทึกสถานะคำขอและสถานะขนส่ง
- การ export CSV สำหรับระบบไปรษณีย์
- การ import tracking กลับเข้าระบบ
- การตรวจ duplicate registration
- การควบคุมสิทธิ์เข้าถึง API พนักงาน

## ข้อมูลทดสอบ

ใช้ข้อมูลจำลองเท่านั้น ห้ามใช้ข้อมูลลูกค้าจริงในการทดสอบที่ไม่จำเป็น

- ชุดข้อมูลตัวอย่าง: `docs/test-input-data.md`
- เลข tracking ตัวอย่างรูปแบบ Thailand Post: `JC012366691TH`
- URL ระบบจริง: `http://maho.kitaith.com:18080`

## TC-PUB-001 ส่งแบบฟอร์มลงทะเบียนสำเร็จ

Precondition:
- เปิดหน้า `http://maho.kitaith.com:18080/`

Steps:
1. กรอกชื่อ-นามสกุล
2. กรอกเบอร์โทรศัพท์อย่างน้อย 9 หลัก
3. กรอกช่องทางติดต่ออย่างน้อย 1 อย่าง: อีเมล, LINE ID หรือ Facebook Messenger
4. เลือกช่วงอายุ
5. เลือกความสนใจสุขภาพ
6. เลือกประสบการณ์กับ มะโฮ
7. กรอกชื่อผู้รับและที่อยู่จัดส่งครบถ้วน
8. ติ๊กยินยอมใช้ข้อมูลส่วนบุคคล
9. กดส่งแบบฟอร์ม

Expected Result:
- ระบบบันทึกข้อมูลสำเร็จ
- แสดง card "ส่งแบบฟอร์มเรียบร้อย"
- แสดงหัวข้อ "ลงทะเบียนสำเร็จ"
- แสดงเลขรายการภายในรูปแบบ `MSYYYYMMDD0001`
- มีปุ่ม `ตกลง` เพื่อปิด card
