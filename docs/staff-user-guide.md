# Mahosample Staff User Guide

คู่มือฉบับนี้สำหรับพนักงานที่ดูแลรายการลงทะเบียนรับตัวอย่าง มะโฮ การจัดส่ง และการนำเข้าเลข tracking

## 1. เข้าใช้งาน

1. เปิดหน้า `http://maho.kitaith.com:18080/staff`
2. กรอก email และ password ที่ได้รับจากผู้ดูแลระบบ
3. กด `Login`

หาก login ไม่สำเร็จ ให้ตรวจสอบ email/password หรือแจ้งผู้ดูแลระบบให้ตรวจสถานะบัญชี

## 2. หน้า Dashboard

หน้า Dashboard ใช้ดูรายการล่าสุดและทำงานเร็วกับแต่ละคำขอ

ข้อมูลสำคัญที่เห็น:
- ชื่อลูกค้า
- เบอร์โทรศัพท์
- จังหวัด
- สถานะคำขอ
- สถานะขนส่ง
- เลข tracking
- หมายเหตุ

รายการที่ยังไม่มี tracking จะถูก highlight เพื่อให้เห็นว่ายังต้องดำเนินการจัดส่งหรือรออัปเดตเลขพัสดุ

## 3. ความหมายของสถานะคำขอ

- `รอตรวจสอบ`: ลูกค้าส่งฟอร์มเข้ามาแล้ว รอพนักงานตรวจ
- `อนุมัติแล้ว`: ตรวจแล้ว ส่งตัวอย่างได้
- `ไม่ผ่านเงื่อนไข`: ไม่เข้าเงื่อนไขกิจกรรม
- `แพ็กแล้ว`: เตรียมสินค้าและที่อยู่สำหรับจัดส่งแล้ว
- `จัดส่งแล้ว`: ส่งพัสดุแล้ว
- `เสร็จสิ้น`: กระบวนการจบแล้ว
- `ยกเลิก`: ยกเลิกรายการ

## 4. ความหมายของสถานะขนส่ง

- `ยังไม่พร้อมส่ง`: ยังไม่เข้าสู่ขั้นตอนจัดส่ง
- `พร้อมส่ง`: พร้อม export เพื่อส่งข้อมูลให้ระบบขนส่ง
- `จัดส่งแล้ว`: มีการจัดส่งและมีเลข tracking แล้ว
- `นำจ่ายสำเร็จ`: ลูกค้าได้รับพัสดุแล้ว
- `จัดส่งไม่สำเร็จ`: ขนส่งไม่สำเร็จ ต้องตรวจสอบต่อ

## 5. ปุ่มบันทึกคำขอ

ใช้สำหรับบันทึกข้อมูลด้านคำขอ เช่น:
- สถานะคำขอ
- หมายเหตุภายใน

ตัวอย่างการใช้งาน:
1. เลือกรายการ
2. เปลี่ยนสถานะคำขอเป็น `อนุมัติแล้ว`
3. ใส่หมายเหตุ เช่น `ตรวจสิทธิ์แล้ว ส่งได้`
4. กด `บันทึกคำขอ`

ปุ่มนี้ไม่ใช่ปุ่มสำหรับบันทึกเลข tracking โดยตรง

## 6. ปุ่มอัปเดตขนส่ง

ใช้สำหรับบันทึกข้อมูลด้านการจัดส่ง เช่น:
- สถานะขนส่ง
- เลข tracking

ตัวอย่างการใช้งาน:
1. เลือกรายการ
2. ใส่เลข tracking เช่น `JC012366691TH`
3. เปลี่ยนสถานะขนส่งเป็น `จัดส่งแล้ว`
4. กด `อัปเดตขนส่ง`

เมื่อมีเลข tracking ระบบจะสร้าง Tracking URL ให้อัตโนมัติ เช่น `https://track.thailandpost.co.th/?trackNumber=JC012366691TH`

## 7. หน้าตารางข้อมูลเต็ม

เปิดหน้า `http://maho.kitaith.com:18080/staff/requests`

หน้านี้ใช้ดูข้อมูลที่บันทึกไว้ทั้งหมดในรูปแบบตาราง รวมถึง:
- ข้อมูลผู้ลงทะเบียน
- ช่องทางติดต่อ
- ประสบการณ์กับ มะโฮ
- ข้อมูลผู้รับ
- ที่อยู่จัดส่ง
- สถานะคำขอ
- สถานะขนส่ง
- Tracking
- Tracking URL
- วันที่ส่ง
- วันที่ลงทะเบียน
- วันที่อัปเดตล่าสุด

คลิกที่รายการในตารางเพื่อเปิดรายละเอียด และแก้ไขสถานะคำขอหรือสถานะขนส่งจาก drawer ด้านข้าง

## 8. การค้นหาและจัดเรียงในตาราง

ที่ header ตารางสามารถใช้งานได้ดังนี้:
- คลิกชื่อ column เพื่อ sort
- กรอกคำค้นใต้ column เพื่อ filter
- เลือก dropdown สำหรับสถานะหรือค่าที่มีตัวเลือก
- ใช้ filter วันที่แบบช่วงเวลาใน `วันที่ส่ง` และ `วันที่ลงทะเบียน`

การ filter วันที่:
1. ใส่วันที่เริ่มต้นในช่องแรก
2. ใส่วันที่สิ้นสุดในช่องที่สอง
3. ระบบจะแสดงเฉพาะรายการที่อยู่ในช่วงวันที่นั้น

หน้าจอจะแสดงผลสูงสุดครั้งละ 100 รายการเพื่อความรวดเร็ว แต่การ export CSV จากหน้านี้จะ export ข้อมูลทั้งหมดที่ตรงกับ filter

## 9. Tracking URL

ถ้ารายการมีเลข tracking แล้ว column `Tracking URL` จะแสดงเป็นลิงก์ คลิกเพื่อเปิดหน้า Thailand Post ได้ทันที

ตัวอย่าง:
`https://track.thailandpost.co.th/?trackNumber=JC012366691TH`

## 10. Export CSV สำหรับไปรษณีย์

ใช้เมื่อต้องการส่งข้อมูลผู้รับไปยังระบบขนส่ง

เงื่อนไขของ export:
- export เฉพาะรายการที่ tracking ยังว่าง
- ชื่อไฟล์เป็น `ImportRecipientBook_yyyy-mm-dd.csv`
- column `RecipientCode` คือเลขรายการภายใน เช่น `MS202609020012`

ขั้นตอน:
1. เปิดหน้า `/staff`
2. ตรวจว่ารายการที่ต้องส่งมีสถานะพร้อมส่งและยังไม่มี tracking
3. กด export สำหรับไปรษณีย์
4. นำไฟล์ CSV ไปใช้กับระบบขนส่งตามขั้นตอนของผู้ให้บริการ

## 11. Import tracking กลับเข้าระบบ

ใช้หลังจากระบบขนส่งมีเลข tracking แล้ว

รองรับ:
- CSV ที่มี `request_no`, `tracking_number`, `shipping_status`, `shipped_at`
- KEX XLSX ที่มี `รหัสผู้รับ` และ `เลขนำส่งพัสดุ`

ข้อสำคัญ:
- `รหัสผู้รับ` ต้องเป็นเลขรายการภายในของระบบ เช่น `MS202609020012`
- ถ้า `รหัสผู้รับ` ไม่ตรง ระบบจะแสดงเป็น not found

ขั้นตอน:
1. เปิดหน้า `/staff`
2. เลือกไฟล์ import
3. กด import tracking
4. ตรวจผลลัพธ์ total, success, not found และ failed
5. เปิดรายการในตารางเพื่อยืนยันว่า tracking ถูกอัปเดต

## 12. เช็คสถานะให้ลูกค้า

เมื่อลูกค้าได้รับเลข tracking แล้ว ลูกค้าสามารถเช็คได้ 2 ทาง:
- หน้าเว็บ `http://maho.kitaith.com:18080/tracking`
- หน้า Thailand Post จาก Tracking URL

พนักงานควรส่งเลข tracking ให้ลูกค้าทาง LINE ID หรือ Facebook Messenger ตามช่องทางที่ลูกค้าให้ไว้

## 13. แนวทางปฏิบัติเรื่องข้อมูลส่วนบุคคล

- ใช้ข้อมูลลูกค้าเพื่อการตรวจสอบสิทธิ์ ติดต่อกลับ และจัดส่งตัวอย่างเท่านั้น
- ห้าม export หรือส่งต่อข้อมูลโดยไม่จำเป็น
- ห้ามใส่ข้อมูลลูกค้าจริงใน prompt AI หรือเอกสารสาธารณะ
- ใช้ข้อมูลจำลองเมื่อทดสอบระบบ
- หากพบข้อมูลซ้ำ ให้แจ้งลูกค้าติดต่อเจ้าหน้าที่ แทนการให้ลงทะเบียนซ้ำ

## 14. ปัญหาที่พบบ่อย

ส่งฟอร์มไม่ได้:
- ตรวจว่ากรอกข้อมูลบังคับครบ
- ต้องมีช่องทางติดต่ออย่างน้อย 1 อย่าง
- ต้องติ๊ก PDPA
- ถ้าขึ้นว่าซ้ำ ให้ตรวจเบอร์หรือที่อยู่กับรายการเดิม

Import แล้ว not found:
- ตรวจว่าไฟล์ใช้เลขรายการภายใน `MS...` ใน column ที่ใช้จับคู่
- ตรวจว่าเลขรายการมีอยู่ในระบบจริง

Tracking URL ไม่ขึ้น:
- ตรวจว่ารายการมีเลข tracking แล้ว
- กด `อัปเดตขนส่ง` หลังกรอก tracking
